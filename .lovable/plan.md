
## תיקון בעיית התפריט במובייל - לא ניתן ללחוץ על ההמבורגר אחרי גלילה

### הבעיה
כשנכנסים לעמוד שירותים (או כל עמוד אחר) וגוללים למטה, ה-Header נעלם לגמרי ומקבל `pointer-events-none`. כפתור ההמבורגר הופך ללא לחיץ עד שגוללים חזרה לראש העמוד (`scrollY <= 2`).

### הפתרון
לשנות את הלוגיקה כך שבמובייל, ה-Header תמיד יישאר נגיש (לפחות כפתור ההמבורגר), גם כשגוללים למטה. שתי אפשרויות:

**אפשרות מומלצת:** במובייל, ה-Header ייעלם בגלילה למטה ויופיע מחדש בגלילה למעלה (כמו שרוב האפליקציות עובדות), במקום להופיע רק בראש העמוד.

### פרטים טכניים

**קובץ: `src/components/Header.tsx`**

1. שינוי לוגיקת הגלילה (שורות 64-72): במקום `scrollY <= 2`, לעקוב אחרי כיוון הגלילה - אם גוללים למעלה, להראות את ה-Header; אם גוללים למטה, להסתיר אותו.

2. הסרת `pointer-events-none` מהתנאי (שורה 108): גם כשה-Header מוסתר, לא לחסום אינטראקציות לגמרי, או לחלופין להבטיח שהמנגנון החדש מספיק מגיב.

```text
לוגיקה חדשה:
- לשמור את scrollY הקודם ב-useRef
- אם scrollY הנוכחי < הקודם (גלילה למעלה) -> isVisible = true
- אם scrollY הנוכחי > הקודם (גלילה למטה) -> isVisible = false
- אם scrollY <= 2 (ראש העמוד) -> isVisible = true
- אם mobileOpen -> תמיד visible
```
