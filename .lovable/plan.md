
# תוכנית: דמות גולש סנפלינג שיורדת עם הגלילה

## סקירה כללית
נוסיף דמות של גולש סנפלינג (איש על חבל) שתהיה קבועה בצד העמוד ותנוע למטה יחד עם גלילת המשתמש - כאילו הוא יורד במורד הבניין.

## עיצוב ויזואלי

```text
+------------------+
|  Header          |
+------------------+
|                  |
|  Content    [🧗] |  <-- דמות על חבל בצד ימין
|            ||    |      החבל משתרך מלמעלה
|            ||    |
|  Section   ||    |
|            ||    |
|            [🧗] |  <-- הדמות זזה למטה עם הגלילה
|            ||    |
+------------------+
```

## פרטים טכניים

### 1. קומפוננטה חדשה - `RappellingFigure.tsx`
- **מיקום**: קבוע (fixed) בצד ימין של המסך
- **חבל**: קו אנכי מהחלק העליון של המסך עד לדמות
- **דמות**: אייקון/SVG של אדם על חבל סנפלינג
- **תנועה**: `translateY` מחושב לפי `window.scrollY`
- **גבולות**: הדמות לא תצא מגבולות המסך (min/max)

### 2. לוגיקת הגלילה
```typescript
// פסאודו-קוד
const scrollProgress = window.scrollY / (document.body.scrollHeight - window.innerHeight);
const figureY = scrollProgress * (viewportHeight - figureSize);
```

### 3. עיצוב הדמות
- SVG פשוט וסכמטי של גולש סנפלינג
- החבל: קו דק שמתחיל מלמעלה ומסתיים בדמות
- אפקט subtle shadow לעומק
- אנימציה קלה של "נדנוד" אופציונלית

### 4. שילוב ב-Index.tsx
- הוספת הקומפוננטה ברמה העליונה (מחוץ ל-main)
- תהיה מוסתרת במובייל (רק דסקטופ)

### 5. סגנון CSS נוסף
- כללי z-index מתאימים כדי שהדמות תהיה מעל התוכן אבל מתחת לכפתורים צפים
- `will-change: transform` לביצועים חלקים
- `pointer-events: none` כדי לא לחסום לחיצות
